# Image Gallery

An interactive Image Gallery web application built using HTML, CSS, and JavaScript.

## Features

* Real-time image search
* Category-based image filtering
* Lightbox image viewer
* Previous and Next image navigation
* Like/Favorites functionality
* Download tracking
* My Activity section:
  * Home
  * Favorites
  * Downloads
* Local Storage support for persistent likes and downloads
* Responsive and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## How to Run

1. Clone the repository:
   git clone https://github.com/pavani0602/image-gallery.git
2. Open `index.html` in your browser.

      OR

Visit the live demo:
https://pavani0602.github.io/image-gallery/
